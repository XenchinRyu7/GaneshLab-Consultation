# Authentication System Documentation (Updated)

## Overview

Sistem authentication menggunakan **custom implementation** dengan:

- **Supabase PostgreSQL** - Hanya sebagai database (bukan Supabase Auth)
- **bcryptjs** - Password hashing
- **JWT (jose)** - Session management
- **Prisma** - Database ORM

## Architecture

### Flow Authentication

1. **Client Request Access** (Get Started Page)
   - Client mengisi form di `/get-started`
   - Request dikirim ke sistem (backend/admin)
   - Admin review request dan membuat credential

2. **Admin Creates Credential**
   - Admin membuat user di database dengan:
     - Email (dari form request)
     - Random password (generated by admin/system)
     - Name, role, avatar_color
   - Password di-hash menggunakan bcrypt
   - Data disimpan di tabel `user_profiles`

3. **Client Login**
   - Client login dengan email + password yang diberikan admin
   - Sistem verify password dengan bcrypt
   - Jika valid, create JWT session
   - Session disimpan di HTTP-only cookie

## Database Schema

### user_profiles Table

```sql
CREATE TABLE user_profiles (
  id UUID PRIMARY KEY,
  email TEXT UNIQUE NOT NULL,
  password TEXT NOT NULL, -- Hashed password (bcrypt)
  name TEXT NOT NULL,
  role UserRole NOT NULL DEFAULT 'client',
  avatar_color TEXT,
  phone TEXT,
  created_at TIMESTAMPTZ,
  updated_at TIMESTAMPTZ
);
```

**Important:**

- Password disimpan di database (hashed dengan bcrypt)

## Implementation

### 1. Password Hashing

```typescript
import { hashPassword, verifyPassword } from "@/lib/auth";

// Hash password saat create user
const hashedPassword = await hashPassword("plainPassword123");

// Verify password saat login
const isValid = await verifyPassword("plainPassword123", hashedPassword);
```

### 2. Session Management

```typescript
import { createSession, getSession, deleteSession } from "@/lib/auth";

// Create session after login
await createSession(user);

// Get session
const user = await getSession();

// Delete session (logout)
await deleteSession();
```

### 3. Login Flow

```typescript
import { login } from "@/lib/auth";

const result = await login(email, password);

if ("error" in result) {
  // Handle error
} else {
  // User logged in, session created
  const { user } = result;
}
```

## Security

### 1. Password Security

- Password di-hash dengan bcrypt (10 rounds)
- Password tidak pernah disimpan sebagai plain text
- Password verification menggunakan bcrypt.compare()

### 2. Session Security

- JWT token disimpan di HTTP-only cookie
- Token expires setelah 7 hari
- Token signed dengan AUTH_SECRET
- Secure flag enabled di production

### 3. Route Protection

- Middleware protect all routes except public routes
- Public routes: `/auth/login`, `/get-started`, `/`
- Protected routes require valid session

## Flow Diagram

```
1. Client Request
   └─> Get Started Form
       └─> Submit Request
           └─> Admin Review

2. Admin Creates User
   └─> Generate Random Password
       └─> Hash Password (bcrypt)
           └─> Insert to Database
               └─> Send Credentials to Client

3. Client Login
   └─> Enter Email + Password
       └─> Verify Password (bcrypt)
           └─> Create JWT Session
               └─> Store in Cookie
                   └─> Redirect to Dashboard
```
